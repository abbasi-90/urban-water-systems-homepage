# SMART UWSS Homepage Redesign Mockup

A redesigned homepage concept for SMART UWSS (Smart Urban Water Supply Systems), the HKUST research program on smart urban water supply systems, built for the Urban Water Systems website refresh proposal.

- Live site: https://www.urbanwatersystems.com/home
- All copy is built only from facts verified on the program's own live pages (research, patents, grants, team).
- Design: deep blues and teal, real photography, scroll triggered motion, animated pipeline diagram.

- `index.html` — the full homepage mockup, self contained.
